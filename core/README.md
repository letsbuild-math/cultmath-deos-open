# Core

Decisions, briefs, controls, gates, failures, questions, writing, rhythm and the six-lens board. Run these on every job.

| Standard | The one line |
|---|---|
| [C1 · Decision Record](C01_decision_record.md) | A decision you did not write down cannot be reviewed, defended or learned from. |
| [C2 · Cutting a Decision Down](C02_cutting_a_decision_down.md) | Before you optimize a plan, delete the parts of it that should not exist. |
| [C3 · Brief Written First](C03_brief_written_first.md) | Write down what you expect to find, and what would prove you wrong, before you look. |
| [C4 · Control](C04_control.md) | A control is a claim about what "no effect" looks like. Write it down before you run. |
| [C5 · Gate](C05_gate.md) | The verdict is what the check printed, not what you hoped it meant. |
| [C6 · Missing Signal Is Not Good News](C06_missing_signal_is_not_good_news.md) | An absence is not a fact. A check that has never gone red is a hope. |
| [C7 · Judgment You Can Be Wrong About](C07_judgment_you_can_be_wrong_about.md) | No verdict without a range, and no judgment without the thing that would prove it wrong. |
| [C8 · Open Question Register](C08_open_question_register.md) | Write down the questions whose answers would change a decision, and do not let them rot. |
| [C9 · Failure Register](C09_failure_register.md) | Name the ways you usually fail before they happen, and log every time they do. |
| [C10 · Every Finding Comes With a Path](C10_every_finding_comes_with_a_path.md) | No honest read without a live path. No path the reader cannot walk. |
| [C11 · Write for One Reader](C11_write_for_one_reader.md) | Pick the one person who has to act on this, and write so they can act on it after one read. |
| [C12 · The Rhythm](C12_the_rhythm.md) | Close the day, review the week, check the system every month, and keep the records current. |
| [C13 · The Six-Lens Board](C13_six_lens_board.md) | Read every big decision through six executive seats, then name the one course that satisfies most of them. |
