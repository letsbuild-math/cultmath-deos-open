# C11 · Write for One Reader

**Module:** Core · **Version:** 1.0 · **From DEOS:** cm_36, cm_13

> **Pick the one person who has to act on this, and write so they can act on it after one read.**

## When to use

- Every memo, brief, deck, email, post, proposal and report.

## The standard

1. **Name the reader and the action** before you write. "The VP of Sales, deciding whether to fund a distributor pilot."
2. **Bottom line early.** The reader should know the answer and what it costs them by the end of the first paragraph. You may delay the twist; never delay the stakes.
3. **Plain language.** Explain the mechanism instead of naming it. No jargon the reader would not use themselves.
4. **Length is bought, not free.** Every extra paragraph costs the reader attention. A long piece is a choice to be read less completely. Sometimes right; never automatic.
5. **Do not write up.** Inflated language reads as less credible, not more.
6. **A detail beats the adjective describing it.** "A write-down large enough to wipe out the year's operating profit" beats "a brutal year."
7. **Put the new information at the end of the sentence.** Old information first, to link back; the point last, where it lands.
8. **Every number has a source and a date.** If you cannot source it, cut it or label it a guess.
9. **Professional standards:** reply within the time you promised; say what you will do and by when; correct your own mistakes before anyone else finds them.

**The last-four-words test.** Read only the last four words of each paragraph, in order. If that reads like the piece's real argument, the structure works.

## How to run it

1. Write the reader and the action at the top of the draft.
2. Write the bottom line in one sentence.
3. Draft.
4. Run the last-four-words test.
5. Cut every sentence the reader does not need to act.
6. Check every number for a source and date.

## Done when

- The reader could act on it after one read.
- Every number is sourced.
- The last-four-words test reads as the argument.

## Common failures

- **Writing for everyone.** It lands with no one.
- **Throat-clearing openings.** Cut the first paragraph and see if anything is lost.
- **Hedge stacks.** "It may potentially suggest." State it or cut it.

## Template

```markdown
**Reader:** [name or role]
**Action they need to take:**
**Bottom line (one sentence):**
**Numbers and sources:**
- [figure] · [source] · [date]
```
