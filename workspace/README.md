# Workspace

Copy this folder into a place you own. File names start with the date: `2026-11-16_short-name.md`.

| Folder | Holds | Standard |
|---|---|---|
| `decisions/` | One file per decision | C1 |
| `research/` | Briefs (dated before the work) and findings | C3, Research module |
| `failures/` | `register.md` (your modes and protocols) and `log.md` | C9 |
| `questions/` | `register.md`, one row per open question | C8 |
| `reviews/` | `daily/`, `weekly/`, `monthly/` | C12 |
| `published/` | Anything that left your hands | C11, C13 |

Templates in each standard are MIT-licensed. Copy them freely.
