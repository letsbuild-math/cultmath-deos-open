# W2 · Rank by Leverage

**Module:** Projects & People · **Version:** 1.0

> **If you only had ten hours this week, which work would matter most?**

## When to use

- Weekly planning. Any time the list is longer than the week.

## The standard

1. **Score every task on three factors,** 1–3 each:
   - **Value proximity:** how directly and how soon does it move revenue, a target, or the decision your boss cares about most?
   - **Compounding:** does finishing it make future work faster, easier or more valuable?
   - **Dependency:** does something else stall if it is not done?
2. **Sum to a leverage score (3–9) and sort into tiers:**
   - **Tier 1 (8–9):** do this week, in your best hours.
   - **Tier 2 (6–7):** do this week once Tier 1 is done, or schedule a firm date.
   - **Tier 3 (3–5):** batch it, schedule it forward, or drop it.
3. **No more than three Tier 1 items.** If you have more, your scoring is too generous.
4. **Your week's governing priority** (C12) comes from Tier 1.
5. **Rerank weekly.** Leverage changes as work finishes.

## How to run it

1. List every open task.
2. Score each on the three factors.
3. Sort into tiers. Cut Tier 1 to three.
4. Block time for Tier 1 first.

## Done when

- Three or fewer Tier 1 items, each with time blocked.

## Common failures

- **Ranking by urgency** instead of leverage.
- **Everything is Tier 1.**
- **Never dropping Tier 3.**

## Template

```markdown
| Task | Value proximity | Compounding | Dependency | Score | Tier | When |
|---|---|---|---|---|---|---|
```
