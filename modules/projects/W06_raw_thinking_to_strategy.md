# W6 · Raw Thinking to Strategy

**Module:** Projects & People · **Version:** 1.0 · **From DEOS:** cm_05

> **Turn a month of scattered notes, ideas and conflicts into a short, executable plan.**

## When to use

- Monthly, after the health check (C12).
- Any time two strong inputs point in opposite directions and you are stuck.

## The standard

Five stages, in order:

0. **Conflict triage** (only when stuck). Write each conflicting input, who it came from, and what it assumes. Find the assumption they disagree on. Decide what evidence would settle it, and get it, or make a reversible call (C2).
1. **Organize.** Gather every note, idea, worry and lesson from the period. Group them into themes. Do not judge yet.
2. **First principles.** For each theme: what is actually true, regardless of how it was done before? What is the binding constraint?
3. **Critique and sharpen.** Argue against your own conclusions. Use the six seats (C13). Cut what does not survive.
4. **Action plan.** No more than three priorities for the next period, each with an owner, a first step, a measure and a date. Everything else is explicitly not this month.

**Rules:**

- Stage 1 is not skipped because it feels slow. It is where the patterns show.
- The plan names what you will not do.

## How to run it

1. Block 60–90 minutes.
2. Run stages 1–4 (and 0 if stuck).
3. Turn priorities into Tier 1 tasks (W2).
4. File the plan and review it next month.

## Done when

- Three or fewer priorities, each with owner, first step, measure and date.
- A "not this month" list.

## Common failures

- **Jumping to the plan** without organizing.
- **Ten priorities.**
- **No critique stage,** so the plan is the first idea.

## Template

```markdown
## [Month] strategy
0. Conflict (if any): inputs · disputed assumption · evidence needed · call
1. Themes:
2. First principles per theme:
3. What did not survive critique:
4. Priorities: | Priority | Owner | First step | Measure | Date |
**Not this month:**
```
