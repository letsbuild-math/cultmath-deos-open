# W5 · Capture the Session

**Module:** Projects & People · **Version:** 1.0

> **Capture a long working session within 24 hours, before what it produced evaporates.**

## When to use

- Within 24 hours of any working session that produced several deliverables, touched several projects, or made decisions.

## The standard

1. **Ten to fifteen minutes.** The session did the hard work. This only captures it.
2. **Five fields:**
   1. **Focus:** what the session was for, in one line.
   2. **Built:** each deliverable, with a link.
   3. **Decided:** each decision. File a record (C1) for any that matter.
   4. **Learned:** what you now know that you did not before, including what went wrong (C9).
   5. **Still open:** what is unfinished, with an owner and a next step. Questions go to the register (C8).
3. **Where it touched:** which projects, documents or systems changed. Update those records (C12).
4. **The weekly review reads these.** Do not re-derive decisions the capture already named.

## How to run it

1. Open the template within 24 hours.
2. Fill the five fields from your notes and the files you changed.
3. File decision records and register questions.
4. Update any records the session changed.

## Done when

- Every deliverable is linked, every decision recorded, every open item owned.

## Common failures

- **Waiting a week,** when half of it is forgotten.
- **Listing activity** instead of output.
- **Open items with no owner.**

## Template

```markdown
# Session capture · [date]
- **Focus:**
- **Built:** [links]
- **Decided:** [→ C1 records]
- **Learned:**
- **Still open:** [owner · next step]
- **Touched:** [projects / records updated]
```
