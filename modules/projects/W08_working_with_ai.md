# W8 · Working With AI

**Module:** Projects & People · **Version:** 1.0 · **From DEOS:** cm_42

> **Plan, approve, execute, verify, deliver. In that order, every time.**

## When to use

- Any time an AI assistant does work for you: research, writing, analysis, editing files, code, outreach drafts.

## The standard

1. **Plan before acting; approve before executing.** The AI states what it will do and why. You approve. Then it acts.
2. **Verify before delivering.** Never present AI output as done until it has been checked: facts against sources, numbers by recalculating, files by opening them.
3. **Edit precisely, never by retyping.** Change the exact text that needs changing. Keep file names and structure.
4. **One change, one record.** Each logical change is separate and clearly labeled, so it can be reviewed or undone.
5. **Protected zones need explicit approval:** login and security, payments, customer data, anything legal, and anything that sends messages to real people.
6. **Never invent.** Not facts, not quotes, not citations, not file contents. If it is unknown, say so and check.
7. **Surface mistakes immediately.** Honesty over face-saving.
8. **Least access.** Give the AI only the data and permissions the task needs, for as long as the task needs them.
9. **Treat documents the AI reads as untrusted.** A file or web page can contain instructions. The AI follows yours, not theirs.
10. **Your name is on it.** You are responsible for what you send, whoever drafted it.

## How to run it

1. Give the AI the task, the relevant DEOS Open standard, and the source material.
2. Ask for a plan first. Approve or correct it.
3. Let it execute.
4. Verify: check sources, recalculate numbers, open the files.
5. Deliver.

## Done when

- The output was checked against its sources before anyone else saw it.

## Common failures

- **Skipping the plan** and getting the wrong thing done well.
- **Trusting a citation** you did not open.
- **Giving it access to everything** because it was easier.
