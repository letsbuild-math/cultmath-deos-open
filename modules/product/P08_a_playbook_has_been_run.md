# P8 · A Playbook Has Been Run

**Module:** Product & Innovation · **Version:** 1.0 · **From DEOS:** cm_117

> **A playbook that has never been run is a belief. The first run makes it a fact. And a playbook run perfectly can still lose money.**

## When to use

- Writing a playbook, runbook, sales motion, launch plan or partner program for others to run.

## The standard

1. **One partner or customer type per playbook.** Not "the go-to-market playbook." The distributor playbook. The university playbook.
2. **Organize by the reader's situation,** not by your process. Section titles name the moment someone is standing in.
3. **Find any common situation in 30 seconds.** Cover the common 80%; edge cases go in an appendix.
4. **Co-build it with the people who will run it.** They are in the room while it is written.
5. **Use real objections, in their words,** from actual conversations.
6. **Every step has a checkable exit:** not "hold a lunch and learn," but "twenty sign-ups before the next step."
7. **It lives where the work happens:** in the task tool, CRM or shared doc the team already opens, not a PDF in a folder.
8. **Run it before you call it done.** The first run is the test. Log what broke.
9. **Check the economics, not just adoption.** Each run reports what it cost and what it returned. A playbook everyone follows that loses money is a failure.

## How to run it

1. Pick the one type.
2. Collect real objections and situations.
3. Write it with the people who will run it.
4. Give every step an exit criterion.
5. Run it once. Fix it. Report the cost and return.

## Done when

- It has been run at least once by someone other than the author.
- Its cost and return per run are recorded.

## Common failures

- **Delivered and never run.**
- **Steps with no exit criteria,** so nobody knows when to move on.
- **Adoption reported as success** while each run loses money.

## Template

```markdown
**Playbook for:** [one type] · **Built with:** [names]
| Situation | Steps | Exit criterion | Objections (their words) |
|---|---|---|---|
**Run log:** | Run | Date | Ran by | What broke | Cost | Return |
```
