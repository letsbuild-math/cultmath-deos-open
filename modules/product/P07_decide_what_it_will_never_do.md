# P7 · Decide What It Will Never Do

**Module:** Product & Innovation · **Version:** 1.0

> **A system that survives has decided in advance what it will never do. A boundary that has to be remembered is not a boundary.**

## When to use

- Designing a product, a process, a budget rule, a brand guardline, or anything that will run without you watching.

## The standard

1. **Four layers, each with one job:**

   | Layer | Its only job | How it fails |
   |---|---|---|
   | **1 · Facts** | Hold the real state: money, inventory, data, dates. No strategy. | Deciding on a signal instead of a fact. |
   | **2 · Constraints** | Pass/fail limits. Binary. No interpretation. | A rule stated as a preference, or living only in someone's head. |
   | **3 · Judgment** | Reasoning inside the limits: adapting, choosing, changing course. | Rigidity dressed as rigor. |
   | **4 · Surface** | What people see: the page, the deck, the habit. | Fixing the surface when the fault is two layers down. |

2. **Layers 1 and 2 must be boring.** Cleverness belongs in 3 and 4. Clever constraints get argued with.
3. **Keep a constraint register.** Each constraint: what it forbids, the trigger, where it is enforced, and its status.
4. **Three tests for a new constraint:**
   1. What worst-case failure does it prevent? If you cannot name a loss, it is a preference.
   2. Can a tired person check the trigger without context? If not, rewrite it or move it to judgment.
   3. Have you watched it fail on purpose? If not, it is CONFIGURED, not LIVE.
5. **Enforce constraints in the system,** not in memory: a required field, a spending cap, an approval step, a blocked word list.

## How to run it

1. List the things the system must never do.
2. Run each through the three tests.
3. Enforce each one in the system and test it.
4. Mark it LIVE once it has failed on purpose.

## Done when

- Every constraint has a named loss, a context-free trigger, an enforcement point and a LIVE or CONFIGURED status.

## Common failures

- **"We always try to…"** That is a preference.
- **A constraint enforced only by a person remembering.**
- **Fixing a surface problem** that is really a missing constraint.

## Template

```markdown
| Never does | Loss it prevents | Trigger (context-free) | Enforced where | Failed on purpose? | Status |
|---|---|---|---|---|---|
```
