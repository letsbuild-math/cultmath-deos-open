# R9 · Can This Be Proven?

**Module:** Research · **Version:** 1.0 · **From DEOS:** cm_120

> **Decide whether a campaign can be proven before you build it. A result you cannot attribute looks the same as luck.**

## When to use

- Before launching a campaign, a strategy, a PR push or a go-to-market plan you will later need to prove worked.

## The standard

Five gates, each scored 0–100, then weighted:

| Gate | Weight | The test |
|---|---|---|
| **G1 · Context bar set from outside** | 25 | What does "good" look like in this category, from a source outside your team (a benchmark, the category's past results)? |
| **G2 · Objectives pre-set, specific and dated** | 25 | The target number, the metric and the date, written before launch. |
| **G3 · Unbroken insight chain** | 20 | Can you draw the line from evidence to insight to idea to the metric it should move, with no leap? |
| **G4 · Measurement designed in, baseline captured** | 20 | The tracking, the control (C4) and the "before" number exist before launch. |
| **G5 · Rival explanations named** | 10 | What else could move the metric (season, price, a competitor, a news cycle), and how you will rule each out. |

**Rules:**

- A campaign that fails G2 or G4 cannot be proven, no matter how well it does. Fix them before launch.
- The bar in G1 comes from outside. Your own last campaign is not a context bar.
- Write down the weighted score and what you will fix before launch.

**Discipline notes:**

- **Brand:** name the brand measure (for example, mental penetration, R3) and its baseline.
- **Go-to-market:** name the funnel stage you are moving and its current conversion rate.
- **PR:** separate coverage (output) from what it changed (outcome).

## How to run it

1. Score each gate 0–100 with a one-line reason.
2. Weight and total.
3. Fix any gate below 50 before launch, starting with G2 and G4.
4. File the scored sheet with the campaign brief.

## Done when

- All five gates are scored, with reasons.
- G2 and G4 are above 50 at launch.

## Common failures

- **Objectives written after the results.**
- **No baseline,** so lift cannot be measured.
- **Ignoring the obvious rival,** such as a price cut that ran at the same time.
