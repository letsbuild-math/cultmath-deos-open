# Research

Mapping a market, reading a category and its entry points, testing evidence and signals, and hearing buyers in their own words.

| Standard | The one line |
|---|---|
| [R1 · Map the Ground First](R01_map_the_ground_first.md) | The first thing you produce on a new job, client or venture contains no recommendation. |
| [R2 · Category Read](R02_category_read.md) | Before you advise on a category, find out how it actually decides. |
| [R3 · Category Entry Point Read](R03_category_entry_point_read.md) | Find the situations in which buyers think of the category, then measure which brands come to mind in each. |
| [R4 · Declare the Audit's Question](R04_declare_the_audits_question.md) | An audit answers the question it was built around, and nothing else, including the one you care about. |
| [R5 · Evidence That Proves](R05_evidence_that_proves.md) | Build the artifact so it shows the reader something they could not have known, from sources they can check. |
| [R6 · Test a Signal](R06_test_a_signal.md) | Confirm the cheap-to-fake against the expensive-to-fake before a signal counts. |
| [R7 · What Buyers Actually Said](R07_what_buyers_actually_said.md) | A phrasing you supplied is not a phrasing you found. |
| [R8 · Customer Feedback Review](R08_customer_feedback_review.md) | Feedback that is not recorded, sorted and answered within a week is lost. |
| [R9 · Can This Be Proven?](R09_can_this_be_proven.md) | Decide whether a campaign can be proven before you build it. A result you cannot attribute looks the same as luck. |
| [R10 · Process Diagnosis](R10_process_diagnosis.md) | Map how a process actually runs, find where it leaks, and lock the fix, before you automate anything. |
