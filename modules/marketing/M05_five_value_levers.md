# M5 · Five Value Levers

**Module:** Marketing & Brand · **Version:** 1.0

> **A number without a lever is a fact about activity. A lever without a number is a belief.**

## When to use

- Writing a business case, a results summary, a self-review, a resume line or a case study.

## The standard

1. **Every value claim names one of five levers:**

   | # | Lever | Counts when |
   |---|---|---|
   | 1 | **Revenue added** | It would not have arrived otherwise. State your role: sole, lead or contributing. |
   | 2 | **Recurring cost removed** | Annualized. One-time savings stated separately, never annualized. |
   | 3 | **Time or friction reduced** | A percentage, with the before state named. |
   | 4 | **Risk removed** | A named failure that can no longer happen. The exposure removed, not the process installed. |
   | 5 | **Willingness to pay raised** | Buyers pay more for the same unit because the reason to choose got stronger. |

2. **Every number carries an evidence state:**
   - **ATTESTED:** stated by a third party with no stake in it, in a form you can produce.
   - **MEASURED:** from a source you can produce.
   - **RECONSTRUCTABLE:** recoverable by a named method, not yet recovered.
   - **ABSENT:** no basis. Leave it out of every document.
3. **Achieved or projected.** Mark whether the number happened (past tense, with a date) or was a target. A plan that says "will drive" is not a result.
4. **Interested parties do not attest.** An award entry is written by the team that did the work.
5. **Scope:** the claim covers only what you can show you moved.

## How to run it

1. List each claim.
2. Assign the lever.
3. Mark the evidence state and achieved or projected.
4. Delete ABSENT claims. Rewrite PROJECTED ones as targets.

## Done when

- Every claim names a lever, a number, an evidence state and achieved or projected.

## Common failures

- **"Drove engagement."** No lever, no number.
- **Annualizing a one-time saving.**
- **A target written as a result.**

## Template

```markdown
| Claim | Lever (1–5) | Number | Before state | Evidence (A/M/R) | Achieved / projected | Role |
|---|---|---|---|---|---|---|
```
