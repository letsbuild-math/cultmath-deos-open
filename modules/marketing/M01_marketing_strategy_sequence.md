# M1 · Marketing Strategy Sequence

**Module:** Marketing & Brand · **Version:** 1.0

> **Orient, research backwards, segment, target, then position. In that order.**

## When to use

- Building a marketing strategy for a brand, product, launch or new market.
- When someone asks for positioning or creative before anyone has chosen who it is for.

## The standard

1. **Orient.** Write what you know about the market, the competition, the company's ability to deliver, and the timing. Mark what is known and what is assumed.
2. **Research backwards.**
   1. Name the decision you are about to make.
   2. For each way it could go, write what you would actually do.
   3. If two answers lead to the same action, you do not need research to choose. Stop.
   4. Write the finding you would need to see to choose: a number, a quote, a pattern.
   5. Only now pick the smallest method that produces it.
   6. Decide, and record it (C1).
3. **Segment.** Split the market into 3–6 real groups that differ in what they need and how they buy, not just in demographics.
4. **Target.** Choose the segment to serve. Write down the segments you will refuse, and why. A strategy that serves everyone is not a strategy.
5. **Position.** For the chosen segment: what you are, what you are against, why you win, and the proof. See M4.

**Order holds.** Positioning built before targeting is positioning for nobody.

## How to run it

1. Write a one-page orientation.
2. Run the backwards research on the one or two decisions that matter most.
3. Draft segments. Test that each one would respond differently to the same offer.
4. Choose one. Write the refusals.
5. Write the position.

## Done when

- One target segment chosen and the refused segments named.
- A position with proof, written for that segment.
- Each research effort traced to the decision it served.

## Common failures

- **Research for its own sake.** No decision named.
- **Demographic segments** that all buy the same way.
- **No refusals.**

## Template

```markdown
1. **Orient:** market · competition · capability · timing (known / assumed)
2. **Decision:** · Actions if A / if B · Finding needed · Method
3. **Segments:** [3–6, each with need and buying behavior]
4. **Target:** [one] · **Refused:** [and why]
5. **Position:** see M4
```
